    Case Study: Pāṇini's Grammar (Otto von Böhtlingk, 1887)

    Scholarly digital edition, canonical Sūtra alignment, and Typst vector typesetting for 3,997 Sūtras across 478 pages.

    🔗 Project Repository: github.com/birchville-org/boethlingk
    🔗 Core Pipeline: AlexandriaSandwich

    1. Context & Scope

    Otto von Böhtlingk's edition Pâṇini's Grammatik (2nd edition, Leipzig 1887) is the definitive historical reference work for the grammatical system of the Aṣṭādhyāyī. Across 478 book pages, the work unites three distinct scripts:

    1. Sanskrit in Devanāgarī: 19th-century metal type with complex conjunct ligatures and virāmas.
    2. German in historical Antiqua: Scholarly translation and grammatical commentary.
    3. IAST Transliteration: Latin script with multiple diacritics (ā, ī, ū, ṛ, ṝ, ḷ, ṃ, ḥ, ṅ, ñ, ṭ, ḍ, ṇ, ś, ṣ) and Vedic accent marks.

    This project serves as an end-to-end reference case study for the open-source book digitization pipeline AlexandriaSandwich.

    3. The Böhtlingk Delta in Detail

    3.1 Delta 1: Canonical Sūtra State Machine (scripts/align_mistral_sutras.py)

    The work strictly follows the structural framework of the Aṣṭādhyāyī: * Canonical Structure: 8 Adhyāyas with exactly 4 Pādas each (32 Pādas total) comprising 3,983 Aṣṭādhyāyī Sūtras plus 14 introductory Śiva-Sūtras (3,997 Sūtras total). * Automatic Pāda & Adhyāya Rollover: When the end of a Pāda is reached, the state machine enforces the canonical transition (state["adhyaya"] += 1, state["pada"] = 1), even if the printed colophon is faint or damaged. * Corrigenda Isolation: Böhtlingk's addenda and corrections (pp. 477–478) following the final Sūtra 8.4.68 (अ अ) are isolated and do not contaminate the commentary apparatus.

    3.2 Delta 2: Fuzzy Canonical Matching against Ground Truth

    Worn metal type occasionally caused OCR misidentifications in Devanāgarī numerals (e.g. ८ misread as ६, hence ६५ instead of ८५): * SequenceMatcher Alignment: When a Sūtra number diverges, the normalized Devanāgarī line is matched against the expected text in data/sutras.json. * Correction Threshold: With similarity >= 0.45, the Sūtra index is automatically corrected to the canonical reference. * Long Compounds: Sūtras spanning up to 350 characters without heading markers (e.g. 5.4.77 with 185 characters) are reliably detected via danda delimiter patterns (॥...॥).

    3.3 Delta 3: Modern Typographic Edition (scripts/boethlingk1887_edition.typ)

    A specialized Typst template formats the multi-tier edition: * Per-Sūtra Hierarchy: 1. Devanāgarī heading with canonical index (१.१.१). 2. Academic IAST transliteration (Bold). 3. German translation (Italic). 4. Indented commentary apparatus with Böhtlingk abbreviations (∠±, Kāç., RV.). * Book Design: ISO B5 (176 x 250 mm), font stack (Noto Serif Devanagari + Libertinus Serif), running headers, and 47 hierarchical PDF bookmarks. * Compilation: Executed via python3 scripts/build_typeset_edition.py in ~8.9 seconds.

    3.4 Delta 4: Standardized TEI-P5 XML & EPUB 3

    • TEI-P5 XML (data/tei/boehtlingk1887_p5.xml): 100% schema-valid against TEI All RelaxNG (schemas/tei_all.rng), featuring 3,997 <tei:entry> elements and 478 <tei:pb> page breaks linked to Heidelberg IIIF endpoints.
    • EPUB 3 (boethlingk1887.epub): Reflowable e-book with embedded fonts ensuring diacritic preservation on e-readers.
